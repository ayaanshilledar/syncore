# Syncore

Syncore is a real-time collaborative music and media synchronization platform built with Next.js, Prisma, WebSockets, and Tailwind CSS.

## Features

- Real-time room synchronization
- Interactive audio/video queues
- Modern responsive UI with animations (Lucide, GSAP, Motion)
- PostgreSQL database integration via Prisma

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
